Sonoskope 的第一个开发预览版本：在 macOS 系统层观察音频、蓝牙及网络证据，帮助定位会议声音异常。

## 下载

- Apple Silicon（M 系列）：`Sonoskope-0.1.0-macos-arm64.zip`
- Intel：`Sonoskope-0.1.0-macos-x86_64.zip`
- `SHA256SUMS`：两个下载包的 SHA-256 校验值。

要求 macOS 14.2 或更新版本。解压后将 `Sonoskope.app` 放在稳定的位置（例如 Applications），打开后从菜单栏查看音频状态和设置。

**签名状态：本版本为 ad-hoc 签名、未经 Apple 公证的开发预览包。macOS Gatekeeper 可能阻止直接打开；它不是 Developer ID 正式分发版本。也可以审阅源码并在本机运行 `bash scripts/build-app.sh` 构建。** 仓库为私有时，下载需要具有仓库访问权限的 GitHub 账号。

## 功能

- 原生菜单栏、状态窗口、设置与无声问题通知。
- 音频设备／进程活动及连接变化，按需蓝牙 RSSI。
- 授权后的应用输出音频分析；显式发起的 10 秒麦克风测试。
- 最近 60 秒声音电平和 TCP 探测耗时图表；缺失数据断线、探测失败单独标记。
- 观察事实与疑似原因分开呈现，问题依据、恢复记录、下一步建议和 JSON 导出。
- 七个与真实采集隔离的模拟场景。
- 默认不录制麦克风，不保存或上传原始音频。

## 验证与限制

自动化回归覆盖音频特征、事件合并、恢复、未知状态和图表历史。开发机真实设备／进程／网络启动检查通过；用户确认授予系统音频录制权限后可看到随声音变化的电平。

电平不是音质评分；TCP 探测不是会议实际延迟或丢包率；本地音频不能证明对方听感或耳机实际发声。蓝牙软故障、真实双端会议、麦克风硬件测试、通知送达和长时间误报率仍需实机验收。详细范围见仓库 `docs/validation.md`。
