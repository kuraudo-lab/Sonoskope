# Sonoskope 0.2.0

A shorter path from first launch to useful audio evidence.

- **First-use guide:** three steps introduce the menu-bar app, let you choose monitoring, and show what is actually enabled. Skip or revisit at any time; microphone and output capture remain explicit choices.
- **Compact workspace:** Overview, Trends and Issues replace the long scrolling status page. Read input/output summaries together, inspect full charts when needed, and keep a selected historical issue open as new events arrive.
- **In-app updates:** background checks and verified downloads, followed by **Install and Relaunch** when you choose. Ordinary quitting does not install or interrupt diagnostics. Disable automatic checks in Settings.
- **Signed distribution:** Developer ID signed and Apple-notarized applications, DMGs and PKGs for Apple Silicon and Intel. Update archives additionally carry an EdDSA signature. MIT licensing is included in the app.

## Installation

macOS 14.2 or later. Choose `arm64` for Apple Silicon or `x86_64` for Intel. Open the DMG, drag Sonoskope to Applications, eject the DMG, then launch. PKG and ZIP alternatives are available; `SHA256SUMS` covers all six packages.

**Updating from 0.1.6 or earlier:** quit the old app and install 0.2.0 manually once. These older versions do not contain an updater. Future releases can be installed from within 0.2.0.

## Validation and scope

79 automated tests passed. A disposable signed application completed a real cached update and relaunch, rejected an invalid signature, and stayed unchanged after normal quit. Bilingual native layouts and relocated resources were checked. This remains a preview: minimum-macOS execution, clean-user installation, Intel-native updater execution and physical-device/permission coverage are still separate acceptance work. Local evidence does not establish remote call quality or headset acoustic output. No raw audio is saved.
