Sonoskope 0.1.5 adds installers and completes the new application identity.

## What's changed

- **DMG:** open the disk image and drag Sonoskope onto Applications. Eject the image and launch from Applications.
- **PKG:** use the macOS installer to install or update `/Applications/Sonoskope.app`. The package contains only the app, has no install scripts or background services, and disables relocation so it cannot update a development checkout instead. Quit the previous version before installing; administrator authorization may be requested.
- ZIP downloads remain available for manual placement.
- The new audio-analyzer artwork is now used for the app bundle, in-app heading and menu-bar icon. Earlier versions retained the old waveform in the latter two locations.
- Release automation verifies all formats before publication, including signatures of the embedded apps, version/architecture/icon consistency and installer destination.

## Downloads

Choose `arm64` for Apple Silicon or `x86_64` for Intel:

- `Sonoskope-0.1.5-macos-<architecture>.dmg` — recommended drag-to-install image
- `Sonoskope-0.1.5-macos-<architecture>.pkg` — guided installer
- `Sonoskope-0.1.5-macos-<architecture>.zip` — portable archive
- `SHA256SUMS` — checksums for all six files

Requires macOS 14.2 or later. **This remains an unnotarized developer preview: the app is ad-hoc signed and the installer containers are unsigned.** DMG/PKG packaging does not remove Gatekeeper checks. Updating may require microphone/audio permission again. The existing 69 automated tests remain part of the release checks; package payload checks do not substitute for a clean-machine, notarized installation acceptance test.
