# Sonoskope 0.3.1

The floating monitor now has an optional always-on-top setting, supports dragging, and stays on the desktop where it first appears.

- **Optional always on top:** off by default. The new Settings toggle is saved across launches and changes the existing panel immediately.
- **Movable panel:** drag the panel header to reposition it. Refreshes and hiding/showing the panel preserve its position instead of snapping it back to the upper-right corner. Chart and button interactions remain separate from the header drag area.
- **Single desktop:** the panel no longer appears on every Space or follows desktop switches. Upper-right placement on the active display happens only when the panel is first created, with a single background geometry query.
- **Signed distribution:** Developer ID signed and Apple-notarized applications, DMGs and PKGs for Apple Silicon and Intel, plus signed update ZIPs.

## Installation

Requires macOS 14.2 or later. From 0.2.0 or later, choose **Check for Updates**, then **Install and Relaunch**. For manual installation, quit Sonoskope, choose `arm64` for Apple Silicon or `x86_64` for Intel, and install into Applications. DMG, PKG and ZIP alternatives are available; `SHA256SUMS` covers all six packages.

## Validation and remaining checks

100 automated tests passed, including new regressions for the default window level, saved always-on-top preference, immediate level changes, single-Space configuration and position preservation. Native floating-panel and Settings layouts were rendered and inspected. Required build, whitespace and distribution checks passed.

This remains a preview. Actual mouse dragging, Spaces/fullscreen switching, physical multi-display behavior, real-device monitoring and runtime permission flows require separate manual acceptance. No raw audio is stored, and local PCM metrics do not establish remote audio quality or actual headset acoustic output.
