# Sonoskope 0.3.0

An optional compact floating monitor, persistent panel preferences, and resident windows that stay available after closing.

- **Resident application:** closing a main window hides it without stopping monitoring. After opening a window, both the menu-bar item and Dock icon remain available; clicking the Dock icon reopens status. Use Quit Sonoskope to exit.
- **Optional floating monitor:** off by default. Enable it in Settings to show existing input/output levels and network curves during measured audio activity. It does not enable collectors, request new audio permissions, or add network probes. Silence hides it after five minutes; pause, sleep, demo mode and unavailable readings also hide it. The existing configurable output-silence auto-pause remains separate.
- **Compact presentation:** a borderless 420 × 350 panel with Pause and Close buttons, background opacity adjustable from 40–100% (90% by default), and opaque text and curves. It follows the frontmost app's display near the upper-right corner with an 18-point inset, falling back to the pointer display when window geometry is unavailable. Charts refresh at 1 Hz and geometry queries run off the UI thread.
- **Saved preferences:** closing the panel now hides it only for the current run, preserving the saved opt-in. Use Show floating monitor again in Settings, or relaunch and wait for audio activity. Only the Settings toggle changes the saved enabled state. Previously saved disabled preferences are respected; enable the option once if needed. Pause stops all monitoring without disabling the panel preference.
- **Signed distribution:** Developer ID signed and Apple-notarized applications, DMGs and PKGs for Apple Silicon and Intel, with signed update ZIPs and the existing release identity.

## Installation

Requires macOS 14.2 or later. From 0.2.0 or later, choose **Check for Updates**, then **Install and Relaunch**. For manual installation, quit Sonoskope, choose `arm64` for Apple Silicon or `x86_64` for Intel, and install into Applications. DMG, PKG and ZIP alternatives are available; `SHA256SUMS` covers all six packages.

## Validation and remaining checks

98 automated tests passed, including AppKit window close/reopen and nonactivating panel checks, five-minute visibility, screen-coordinate calculations, opacity persistence and close-versus-disable behavior. A separate isolated app verified preferences across actual process termination and relaunch for enable, close and explicit disable. Bilingual native layouts were rendered and inspected. Required build, whitespace and distribution checks passed.

This remains a preview. Physical multi-display switching, fullscreen/Spaces composition, real-device long-running monitoring and permission flows require separate acceptance. Closing the panel was reproduced as a cause of the preference being disabled; loss after a direct quit without closing the panel was not reproduced. No raw audio is stored, and local PCM metrics do not establish remote audio quality or actual headset acoustic output.
