Sonoskope 0.1.6 makes network probes follow measured audio activity.

## Changes

- Active TCP probes run only when at least one enabled input/output collector has a valid, continuous PCM window above −65 dBFS, received within the last 3 seconds.
- Silence, stopped capture, missing/stale samples, pause, sleep, and demo mode suspend probes. Network path observation remains passive.
- In-flight probes are cancelled when activity ends. Cancellation does not count as a timeout or recovery. Probe windows reset and charts break across inactive periods.
- Rapid activity changes retain the five-second probe cooldown. English and Chinese interfaces show the waiting state.
- No audio capture is enabled automatically by this feature; with no measured audio, probes stay idle.

## Downloads

DMG, PKG, and ZIP are available for Apple Silicon (`arm64`) and Intel (`x86_64`). Requires macOS 14.2 or later. This remains an ad-hoc signed, unnotarized developer preview with unsigned installer containers.
