# Sonoskope 0.3.2

The app icon now has rounded corners, and Settings clearly separates control labels from explanatory text.

- **Rounded app icon:** the icon build applies rounded corners and transparent margins to the traditional macOS icon resource while preserving the original artwork.
- **Clearer Settings:** control labels use medium-weight text, with smaller secondary descriptions directly beneath the corresponding controls. Floating-monitor help now sits with its toggle, and microphone capture implications remain in a separate information row.
- **Signed distribution:** Developer ID signed and Apple-notarized applications, DMGs and PKGs for Apple Silicon and Intel, plus signed update ZIPs.

## Installation

Requires macOS 14.2 or later. From 0.2.0 or later, choose **Check for Updates**, then **Install and Relaunch**. For manual installation, quit Sonoskope, choose `arm64` for Apple Silicon or `x86_64` for Intel, and install into Applications. DMG, PKG and ZIP alternatives are available; `SHA256SUMS` covers all six packages.

## Validation and remaining checks

100 automated tests passed. English and Chinese Settings were rendered in light and dark appearances, and representative renders were visually inspected. Required build and whitespace checks passed. Both architectures pass signing, notarization, stapling and distribution-container validation before publication.

This remains a preview. Finder/Dock icon presentation, clean-machine installation, runtime permission flows and physical-device monitoring require separate manual acceptance. No raw audio is stored, and local PCM metrics do not establish remote audio quality or actual headset acoustic output.
