Sonoskope 0.1.1 adds English and Chinese localization.

## What's changed

- The interface follows the macOS preferred-language order. English and Chinese are supported; other languages fall back to English when no supported preference is available. Chinese regional/script variants share the Simplified Chinese translation. Restart Sonoskope after changing system or app language.
- Localized menus, settings, charts, notifications, permission descriptions, and diagnostic messages.
- Incident history stores message keys and parameters so it can be displayed in either language. Known v0.1.0 messages are migrated when read. Device/app names, system errors, and unknown historical text retain their original wording. The new structured history format requires v0.1.1 or later.
- English `README.md`, Chinese `README_zh.md`, and English release notes.
- Regression coverage for language selection, translation completeness, interpolation, and history migration; offscreen rendering checks for both languages.

## Downloads

- Apple Silicon (M-series): `Sonoskope-0.1.1-macos-arm64.zip`
- Intel: `Sonoskope-0.1.1-macos-x86_64.zip`
- `SHA256SUMS`: SHA-256 checksums for both archives.

Requires macOS 14.2 or later. Extract the ZIP and place `Sonoskope.app` in a stable location such as Applications. Quit the previous version before replacing it.

**This is an ad-hoc signed, unnotarized developer preview. Gatekeeper may prevent direct opening.** You can also build from source with `bash scripts/build-app.sh`. Private repository downloads require an authorized GitHub account. Updating an ad-hoc signed build may require granting audio capture permission again.

## Diagnostic limits

Audio levels are not quality scores, TCP probes do not measure meeting media loss, and local evidence cannot verify the remote listening experience or actual headset sound. Physical Bluetooth faults, real two-endpoint calls, notification delivery, and long-call performance still need acceptance testing. See `docs/validation.md`.
